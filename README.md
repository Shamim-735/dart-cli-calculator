# Dart CLI Calculator

A command-line calculator written in Dart.

## Run
```
dart run bin/calculator.dart          # interactive mode
dart run bin/calculator.dart "2+3*4"  # one-shot mode
```

## Features
- `+ - * / % ^`, parentheses, unary minus
- Constants: `pi`, `e`, `ans` (previous result)
- Functions: `sqrt abs sin cos tan ln log`
- Commands: `history`, `clear`, `help`, `exit`
